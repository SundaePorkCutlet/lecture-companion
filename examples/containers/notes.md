# 이미지와 컨테이너: 복습 노트 예시

**가상 예시입니다.** 프로젝트가 직접 만든 36초 데모의 내용을 바탕으로 편집한 읽기 예시이며, 실제 사용자 문답이나 외부 강의 녹취가 아닙니다. 실행할 때는 에이전트가 실제로 수집한 내용과 저장된 문답으로 새 노트를 만듭니다.

## 강의 핵심

이미지는 컨테이너를 만들 때 사용하는 파일시스템과 설정의 틀입니다. 컨테이너에서는 격리된 프로세스가 실행됩니다. Docker는 이미지를 빌드하고 컨테이너를 생성·관리하는 도구를 제공합니다.

`docker cp`로 실행 중인 컨테이너에 파일을 넣으면 변경 사항을 빠르게 시험할 수 있습니다. 그 변경이 원래 이미지를 다시 빌드하지는 않습니다. 다음에 같은 구성을 만들려면 필요한 파일과 빌드 단계를 Dockerfile에 기록하고 새 이미지를 만듭니다.

## 부연 설명

예를 들어 웹서버의 설정 파일을 컨테이너에 복사해서 시험할 수 있습니다. 이때 수정한 컨테이너 하나와 앞으로 배포할 이미지의 상태를 구분해야 합니다. 시험에 성공한 설정을 빌드 과정에 넣어야 다른 환경에서도 같은 구성을 만들 수 있습니다.

## 질문과 답변 예시

**Q. docker cp로 복사하면 다음 컨테이너가 사용할 이미지도 바뀌어?**

A. 원래 이미지는 바뀌지 않습니다. 복사한 컨테이너의 파일은 바뀌지만, 그 원래 이미지에서 새 컨테이너를 만들면 복사한 파일이 자동으로 들어오지는 않습니다. 데모에서는 필요한 파일을 Dockerfile의 `COPY` 단계에 넣고 이미지를 다시 빌드하는 흐름을 설명합니다.

## 실행한 세션에서 확인할 근거

실제 노트에는 관찰한 자막·선택 화면의 근거, 수집 종료 이유, 저장된 문답의 리비전과 확인하지 못한 내용을 함께 남깁니다. 음성이나 완전한 녹취를 수집한 것으로 표시하지 않습니다.
