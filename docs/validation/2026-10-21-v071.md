## Bugs found by native inspection and review

The first expanded native script passed its coarse PNG assertions, but inspecting the saved image revealed parent-page pixels above the selected iframe. A dedicated nonzero-origin test then failed: the tested native Aside API respected screenshot clip size while ignoring its x/y origin. Both ordinary clipped and `fullPage` variants reproduced the issue.

The adapter now keeps a viewport PNG transient in local memory/IPC. The existing external image worker crops the selected player **before** visual comparison or persistence. The full viewport is never written as a session artifact or returned in an evidence batch. A real green-region regression failed before this fix and passed afterward, including the scrolled page.

Independent review then reproduced an additional proportional-resize defect: inferring DPR only from image/viewport dimensions accepted stale coordinates as a different scale. The adapter now verifies player bounds, viewport dimensions and observed DPR before and after the screenshot. The worker separately validates the PNG dimensions against that observed DPR. Changed geometry or mismatched dimensions reject the frame and stop capture for inspection. New worker and subprocess resize/scroll regressions failed before these checks and passed afterward. These checks bracket the browser operation; they do not claim an atomic layout lock or support for continuously moving players.

The reviewer reran the targeted tests and reported no remaining findings after the geometry correction. Existing ego/Buffer capture behavior, timeout cleanup and serialized REPL handling remain covered.

## Scope and limits

This verifies a short native Aside pipeline through capture, independent Q&A storage and combined export. It does not verify a 25-minute real course, every video provider, protected video, or complete transcription. Cross-origin fallback can miss short captions; it has no reliable media time. Burned-in captions and speech are not reconstructed, and no audio is captured.

This run exercised the public Q&A store while native capture continued; it did not open a new native question-chat window. The separate Codex chat setup remains the host workflow documented and demonstrated in [v0.4](2026-10-20-v04.md). Native Aside chat opening and a Chrome capture adapter are not included.

The collector invoked zero model tasks and reports `tokenUsage: null`. This is not a claim that the tutoring agent, development work, browser tools, or this conversation use zero tokens; no token-saving percentage was measured.
