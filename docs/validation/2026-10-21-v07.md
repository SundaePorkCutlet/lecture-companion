# v0.7 Aside capture validation — 2026-10-21

## Implemented

`tabs --browser aside` lists existing native tabs. `capture --browser aside --tab TARGET_ID --selector CSS` binds only the explicitly selected existing tab and uses Aside's supported persistent MCP `repl` tool. Browser calls are serialized; PNG processing stays in a separate managed Node process. The capture journal feeds the existing independent question context/Q&A and combined notes export. No ego command, separate model task, audio service or npm dependency installation is required for this path.

The CLI is discovered on PATH or its standard official installation paths; an existing absolute `LECTURE_ASIDE` override and `ASIDE_CLI_INSTALL_DIR` are supported. Existing `--account` and `--profile` selection is passed to Aside. The launcher continues to discover the app-managed Node automatically.

The validation-link omission noted during drafting is resolved by this file.

## Limits

Aside snapshot scoping is not strict for orphan frames; the adapter discards every iframe subtree lacking the native reference that proves it was stitched into the selected tree. This can omit unassociated frame content rather than mix it into lecture evidence. Snapshot text can also include slide text inside the player. Native escaping cannot distinguish a source newline from a literal backslash-n, so fallback preserves backslashes; prefer event captions when accessible.

The Aside event probe lease is 60 seconds to tolerate a serialized screenshot before a buffered read. Normal shutdown freezes/drains it; abnormal interruption relies on lease cleanup, which browser throttling can delay. Browser/session loss and errors stop observation without switching to ego or another tab. No complete transcript, speech reconstruction, protected-video bypass, token saving percentage, Chrome adapter or native Aside question-chat opener is claimed.
