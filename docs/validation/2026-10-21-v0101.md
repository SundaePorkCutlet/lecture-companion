## Security regressions and normal controls

Tests reproduce oversized UTF-8 captions, cumulative small-caption journal growth, oversized packets, unsafe metadata, non-progressing shutdown drains, image storage pressure and legacy logs. The original failures were observed before the corresponding fixes. Both event and snapshot capture stop with `resource-limit`, retain the accepted prefix and refuse rejected content. Legacy files and oversized final rows are left untouched. A packet exactly at its byte budget remains accepted, and a lower caller-selected snapshot budget applies to Aside too.

The suite also retains ordinary caption deduplication/repetition/seek behavior, observed media end/player transitions, control-loss cleanup, bounded long-evidence pagination, independent Q&A context/writes, combined exports, image processing, runtime selection and standalone skill installation. Browser APIs are exercised through the existing local fixtures; this release does not add a live browser/session or external model-provider test.

English/Korean README, skill instructions, the technical reference and startup metadata distinguish local storage from host AI processing. The collector has no model API/upload backend, while material read by the host follows its provider/account policy. Visible sensitive data is not automatically redacted. Capture limits do not provide a browser/agent sandbox or a fixed RAM-usage guarantee.
