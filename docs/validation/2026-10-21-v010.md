# v0.10 first-run and release preparation validation

## Changes

- English and Korean entry guides now lead with installation, lecture selection, the actual question chat and final notes. Technical CLI/history moved to `docs/reference.md`.
- A self-authored 36-second silent WebM/HTML lecture ships with the independent skill. `demo --serve` serves only its two assets on localhost; it does not create a fake chat or a study session.
- Capture binds to the original selected player/source. A confirmed source/player change ends the current capture with `stopReason: player-changed`, `completed: false` and an explicit next-lecture choice. Unknown browser/source/image failures remain errors.
- Event and snapshot modes guard screenshots; snapshot reads are checked before and after observation. First resource acquisition is accepted before establishing the media-source baseline. Event queues freeze on a known source replacement and their old evidence is drained.
- `check` explains stopped sessions and offers export; combined exports retain end/boundary records with saved Q&A.
- Public note examples are clearly labeled synthetic. Launch copy and an early-user trial plan are local drafts only.

## Verification

The full Node suite passed **106/106**, including regressions observed failing before the relevant fixes: a confirmed transition becoming a generic error, next-lecture captions entering an emptied source, a snapshot crossing a transition, event-mode screenshot contamination and first media loading being mistaken for a transition.

The native ego sample test observed **6 captions and 6 selected images**, completed on `media-ended`, and exported a synthetic fixture Q&A. It played the 36-second sample at **4× for this test**. A separate cross-origin iframe case saved one caption/image, then stopped on a changed iframe as `player-changed` with `completed: false`. Losing the entire document/probe was rejected. These are synthetic tests, not a new human question-chat trial. The event image guard and initial-loading refinements were added after this ego run and verified with failing/passing regressions and the latest native Aside run below.

The latest native Aside fixture suite passed against the final collector code:

- Player cropping at two scroll positions: one correctly cropped 640×480 image each.
- DOM events: five nonempty captions, including repeated text separated by a clear, and one image.
- TextTrack: three cues, playback changes and an observed media end, plus one image.
- Cross-origin snapshot fallback: one caption/image; outside and sibling-frame content excluded.
- Public CLI: continued capture while a synthetic Q&A was saved, preserved the worker's pending receipt, drained eight events and exported the saved pair.

The crop smoke originally used a fixed 0.8-second deadline and completed its first image processing after that deadline, so no image was published. It now stops after observing the first saved frame, with a ten-second failure bound. This is a test timing correction, not a claim about five-minute setup speed.

The skill validator, `git diff --check` and generated-bundle freshness checks passed. The release ZIP contains the full skill, runtime, sample assets and original licenses. The existing unmodified installed skill was verified and backed up before installing v0.10; its installed demo served both assets successfully without importing the source checkout.

## Limits

No public repository, upload, promotional post or automation was created. No new human side-chat test or independent first-time-user timing was measured in this pass. The earlier live human Q&A trial remains documented in [ego-live](2026-10-21-ego-live.md).

Cross-origin player changes that do not replace or reload the observed iframe cannot always be identified. A complete lecture transcript, universal player support, measured token savings, automatic model wakeups and a universal five-minute setup remain unproven. Changing players stops observation; it does not pause the browser or continue into another lecture.
