# v0.10.1 — Bound lecture capture and clarify AI data flow

This patch fixes resource exhaustion in caption capture and makes the local-storage/AI-provider boundary explicit. Users of v0.10.0 should update their installed skill.

## Security fix

A selected malicious or compromised lecture page could supply large, changing captions that accumulated without a byte quota. Later study and export commands read the entire journal. Event-count limits and model response budgets did not limit host storage or processing.

Both event and snapshot capture now enforce UTF-8 limits before persistence: **64 KiB per caption, 128 KiB per event, 256 KiB per packet, 16 MiB per journal, and 128 MiB for captured journal/PNG evidence**. The browser queue also has a byte budget and reports dropped evidence. Accessibility snapshots are bounded before local parsing. Every journal consumer rejects oversized files and rows, including legacy sessions. Shutdown drains have progress and work limits.

Capture stops with `resource-limit` and `completed: false` when a safety limit is reached. Rejected content is not silently truncated or treated as complete evidence. Earlier accepted evidence and saved Q&A remain available for export when the journal is within its read limit. Existing oversized sessions are preserved for deliberate recovery.

## Data handling

The English/Korean guides, skill instructions and capture startup message now distinguish local evidence from material consumed by the host AI:

- Captions, selected player images and capture metadata are stored in the local session.
- Caption batches, images opened by the agent, summaries and Q&A enter the configured Codex/Claude Code provider's context. Repeated batches can expose substantial lecture content. Provider retention/training settings follow the user's account.
- The collector has no upload backend or separate model API. This does not make the host workflow offline. Visible sensitive information is not automatically redacted.
- Local files are plaintext and remain until deleted. Local deletion does not delete provider-side chat history. Aside transiently transports the full viewport through local memory before saving the cropped player image.

## Install or update

Download **`lecture-companion-0.10.1.zip`** and its matching SHA-256 file. Use your host's skill manager to update `skills/lecture-companion`, or extract the ZIP and run:

```sh
/bin/sh lecture-companion/scripts/install.sh
# Claude Code: add --host claude-code
```

The standalone installer preserves a different existing installation. For a manual update, stop any running capture, move the existing skill folder to a backup outside the host's skills directory, then run the installer. Keep your session data; it is stored separately. A failed installation can be rolled back by restoring the backup. Existing customized skills should be reviewed before replacement.

## Validation

The full automated suite passes **124 tests**, including event/snapshot quota enforcement, UTF-8 boundaries, repeated sublimit inputs, legacy logs, shutdown cleanup, normal evidence pagination, Q&A/export and standalone installation. Bundle freshness and release ZIP contents/checksums are verified. This patch does not claim a new live-course or end-to-end timing measurement.

No audio capture, DRM bypass, automatic public publication or additional model API has been added. Supported browser/runtime requirements remain unchanged.
