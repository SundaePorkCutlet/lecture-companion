# v0.10 — Study a lecture, ask questions, keep the answers

Lecture Companion is an experimental Codex/Claude Code skill for studying subtitled lectures in Aside or ego. Capture continues in the lecture worker while a separate question chat reads fresh evidence when you ask. Saved answers join the final study notes.

## Install

Download **`lecture-companion-0.10.0.zip`** from this release and extract it, then run:

```sh
/bin/sh lecture-companion/scripts/install.sh
# Claude Code: add --host claude-code
# Both hosts: add --host both
```

You can also install the repository's `skills/lecture-companion` folder through your host's skill installer. The complete collector, runtime code, PNG dependency and synthetic demo are included. A supported host-provided runtime is still required; no separate Node/npm installation or source checkout is needed in supported setups.

Open a subtitled lecture and ask Codex:

> Use $lecture-companion to study the lecture in Aside with me. Open a separate question chat and save our Q&A with the final notes.

For ego, replace Aside with ego. In Claude Code use `/lecture-companion` followed by the same request. First-time users can ask to try the built-in synthetic demo instead.

## Included

- Local caption capture and selected player images, with bounded evidence batches.
- A separate question chat with fresh context on each question, plus combined notes and saved Q&A.
- Guided lecture selection in Aside, English/Korean start guides and illustrative notes.
- A self-authored 36-second silent sample, served locally with `demo --serve`.
- Explicit stop reasons for observed media end, player/source changes, user stop and time limits. Guards prevent known transitions from mixing next-lecture evidence into the session.

## Validation and limits

The full automated suite passed **106 tests**. Native Aside capture/Q&A/export and ego synthetic sample collection were exercised; the [validation record](https://github.com/SundaePorkCutlet/lecture-companion/blob/main/docs/validation/2026-10-21-v010.md) distinguishes synthetic checks from the earlier human question-chat trial.

This release requires Aside's official CLI connection or ego's browser skill. Ordinary Chrome is not directly supported. Codex can open the question chat when native chat tools are available; other hosts may require opening a full-tool session manually. No audio is captured, complete transcription is not guaranteed, and inaccessible cross-origin players may require snapshot fallback. Capture cannot wake model turns or automatically follow the next lecture. Your agent still uses its normal allowance or billing.

The ZIP's SHA-256 file is attached alongside it. Source and bundled dependency licenses are included.
