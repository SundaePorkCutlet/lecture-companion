# Early release preparation

These are local drafts and a trial plan. No public repository, post, message or promotion schedule has been created.

## English description

Study a subtitled lecture with your usual AI agent. Lecture Companion captures local captions and selected player screenshots, lets a separate question chat read fresh context, and keeps the answers in your review notes.

## Short launch draft

I built Lecture Companion because I wanted to ask questions while studying a lecture and keep the explanations with my notes.

It is a Codex/Claude Code skill with a bundled local collector. The question chat reads fresh evidence when you ask, while lecture processing continues in the worker chat. At the end, saved Q&A joins the study notes.

There is a built-in 36-second silent sample to try before connecting a course. The first release supports Aside and ego; ordinary Chrome is not directly supported. It needs accessible subtitles, does not capture audio, and does not guarantee a complete transcript. Question-chat opening depends on the host's available tools.

I am looking for a few people who already use these tools to try installation → one question → final notes and tell me where they get stuck.

## Demo recording sequence

Use only the project-authored sample. Show the installation source, a selected lecture title, verified capture and the actual separate question chat. Ask a question while the worker is active, then open the generated notes containing that pair. Show manual host steps if required. Edit waiting time only with a visible cut; do not present prepared examples as a live end-to-end result.

## First trial

Invite 5–10 willing users individually through an appropriate channel. Start with Codex + Aside users, where the guided selection and native chat opener are supported. Record setup conditions, time to the first question, manual assistance, successful export and voluntary repeat use. Fix repeated failures before broadening the launch.

Prepare release notes and channel-specific drafts from verified changes. Track public issues, release downloads and repository activity without collecting lecture content. Deduplicate relevant feedback and produce a compact review when something changes. Public posting and its schedule require a separate, explicit request; this document does not enable posting.
